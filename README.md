# Student Perks

A responsive student benefits discovery portal built as a PBL frontend prototype.

## Features
- Search, filter and sort sample student offers
- Save favourite offers in browser localStorage
- Demo-only student login (no authentication)
- Official provider links and eligibility notes
- Responsive design for mobile and desktop

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish on GitHub Pages
Push these files to a public GitHub repository, then go to **Settings → Pages → Deploy from a branch → main / (root) → Save**.

## Important limitations
This is a frontend demonstration, not a production service. No backend, database, secure authentication, email verification, or admin panel is included. Sample offers are not guaranteed active. Check provider websites for current terms.
